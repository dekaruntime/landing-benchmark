## Caveats specific to this run

- **The machine was busy.** Load average 15.87 on 20 cores. Not all of that was
  the benchmark. Every figure here is probably depressed, and not uniformly.
- **deka's spread is wide** — 137k to 156k, a 14% range across three runs.
  Treat the median as approximate.
- **Bun `reusePort` was not run.** Only the default single-loop configuration was
  measured, so this file has no tuned Bun figure to sit beside Node cluster.
- **deka ran on compiler v1** (`DEKA_COMPILER=v1`). The default compiler (v2)
  cannot serve on this build — see
  [deka#330](https://github.com/dekaruntime/deka/issues/330). The runtime is the
  same either way and the handler is trivial, so this is a runtime measurement
  rather than a compiler one, but it is not the default path.

This run is indicative, not publishable. A clean result wants a quiet machine, a
concurrency sweep, and Bun `reusePort` alongside Node cluster.
